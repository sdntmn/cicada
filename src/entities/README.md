# Слой `entities`

## Назначение
Содержит бизнес-сущности приложения (например, Debtor, Premises, User). Каждая сущность представляет собой объект предметной области с данными и поведением.

## Структура
Каждая сущность имеет следующую структуру:
```
entities/
  <EntityName>/
    index.ts          # Публичный API (экспорт типов, actions, reducers)
    model/
      types/          # Типы TypeScript
      slice/          # Redux slice (состояние, actions, reducers)
      thunk/          # Redux thunks (асинхронные операции)
      service/        # Сервисные функции (трансформации, валидации)
    lib/              # Вспомогательная логика, специфичная для сущности
    ui/               # (опционально) UI-компоненты, связанные с сущностью
```

## Правила
- Сущности не должны зависеть от слоёв `features`, `pages`, `widgets`.
- Допустимы импорты из `shared` и других `entities`.
- Состояние сущности управляется через Redux (slice).
- UI-компоненты, относящиеся только к данной сущности, размещаются в `ui/`. Если компонент используется в нескольких местах, его следует вынести в `shared/ui`.

## Примеры сущностей
- `Debtor` — должник
- `Premises` — помещение
- `User` — пользователь системы
