# Слой `features`

## Назначение

Содержит функциональности (фичи) приложения, которые могут включать пользовательские сценарии, интерактивные элементы, сложную бизнес-логику. Каждая фича представляет собой законченный блок поведения, который может использоваться на нескольких страницах.

## Структура

Каждая фича имеет следующую структуру:

```
features/
  <FeatureName>/
    index.ts          # Публичный API (экспорт компонентов, actions, хуков)
    ui/               # UI-компоненты фичи
      <ComponentName>/
        Component.tsx
        styles.scss
    model/            # (опционально) Логика состояния фичи (slice, thunk, types)
    lib/              # (опционально) Вспомогательная логика, специфичная для фичи
```

## Правила

- Фичи могут зависеть от `entities` и `shared`, но не от `pages`, `widgets` (кроме случаев, когда фича является частью виджета).
- Фича может не иметь UI (только модель) или не иметь модели (только UI).
- Если фича используется только на одной странице, её всё равно следует размещать здесь, а не внутри страницы.
- Избегайте создания фич, которые дублируют логику из `entities` или `shared`.

## Примеры фич

- `GlobalSearch` — глобальный поиск по приложению
- `ChangeDebtStage` — изменение стадии долга
- `HouseMultiSelect` — множественный выбор домов
- `SearchByAccount` — поиск по лицевому счёту
- `SearchByAddress` — поиск по адресу
