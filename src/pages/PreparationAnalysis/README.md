## 🧱 Формат ячейки

- Каждая ячейка состоит из максимум 4 уровней:

- [1] Основной идентификатор
- [2] Уточнение / связь / период
- [3] Контекст (источник, счёт, статус)
- [4] Иконки верификации атрибутов

##### ? Можно расмотреть два варианта - как первый выше и например сделать компактный вид

- [1] [Основной идентификатор • Сумма]
- [2] Иконки верификации атрибутов

```
💡 Иконки отражают статус даже тех данных, которые не отображаются в тексте (например, email или ИНН).
```

## 🎨 Цветовая индикация (иконки)

Для каждого критичного атрибута отображается иконка со статусом:

| Цвет       | Значение                             | Когда применяется                                                              |
| ---------- | ------------------------------------ | ------------------------------------------------------------------------------ |
| ⚪ Серый   | Данные отсутствуют                   | Поле не критично для текущей стадии и дальнейшего перехода на возможные стадии |
| 🟡 Жёлтый  | Данные загружены, но не подтверждены | Поле заполнено (например, из выгрузки), но требует верификации оператором      |
| 🟢 Зелёный | Данные подтверждены и актуальны      | Данные внесены вручную или подтверждены (например, сканом, звонком)            |
| 🔴 Красный | Обязательные данные отсутствуют      | На текущей стадии поле обязательно, но не заполнено → блокирует переход        |

❓ Обязательные параметры для перехода по стадиям:

```
🔴 Если хотя бы один из обязательных параметров не выполнен, соответствующая иконка становится красной, а кнопка перехода — неактивной.
```

- Анализ и сбор данных :
  - ФИО или наименование организации
  - Адрес проживания/регистрации должника (почтовый)
  - адрес (email)

- Претензии:
  - Претензия отправлена (иконка - письмо со стрелочкой из письма - иконка желтая пока не поступило подтверждения доставки)
  - Есть ответа (иконка - письмо со стрелочкой в нутрь письма - желтая пока не вышел период ответа, далее зеленая если есть и красная если нет)

**❓ - еще как вариант - подумать над вариантом с перечеркиванием иконки, галочкой и песчные часы**

- Урегулирование:
  - Нет оплат за определенный период

- Подготовка в суд:
  - ИНН|Паспорт|СНИЛС
  - Данные должника
  - Данные о долге

❓ Формирование (или загрузка) документов при прохождении по стадиям:

- Анализ и сбор данных :
  - Выписка из лицевого счёта
  - Акт сверки
  - Справка о задолженности от ЖКХ/УК

- Претензии:
  - Досудебное требование (претензия)
  - Квитанция об отправке (почта / email)
  - Лог коммуникаций (звонки, письма)

- Урегулирование:
  - Соглашение о реструктуризации (если достигнуто)
  - График погашения
  - Подтверждение частичных оплат

- Подготовка в суд:
  - Исковое заявление
  - Расчёт суммы взыскания (с пени на дату подачи)
  - Копия претензии и подтверждение отправки
  - Документы, подтверждающие личность должника (ИНН, паспорт)
  - Назначение юриста
