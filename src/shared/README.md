# Слой `shared`

## Назначение

Содержит переиспользуемые модули, не зависящие от бизнес-логики: UI-компоненты, утилиты, хуки, API-клиенты, константы, типы. Этот слой используется всеми вышележащими слоями.

## Структура

```
shared/
  api/               # API-клиенты и типы для взаимодействия с бэкендом
    ApiWithAbortController.ts
    Endpoints.ts
    types.ts
    <Entity>Api/     # API для конкретных сущностей
  assets/            # Статические ресурсы (изображения, шрифты)
  constants/         # Константы приложения (строки, числа, перечисления)
  lib/               # Вспомогательные библиотеки
    helpers/         # Утилитарные функции
    hooks/           # Переиспользуемые хуки
    store/           # Глобальное состояние (Redux store)
    types/           # Общие типы TypeScript
    url/             # Утилиты для работы с URL
  ui/                # Переиспользуемые UI-компоненты
    <ComponentName>/
      index.ts
      ui/Component.tsx
      styles.scss
```

## Правила

- Модули в `shared` не должны зависеть от `entities`, `features`, `pages`, `widgets`.
- Допустимы зависимости внутри `shared` (например, `ui` может использовать `lib`).
- Компоненты в `shared/ui` должны быть максимально абстрактными и не содержать бизнес-логики.
- При добавлении нового общего функционала сначала проверьте, нет ли аналогичного в `shared`.

## Примеры

- `shared/ui/Button` — кнопка
- `shared/ui/Table` — таблица
- `shared/lib/hooks/useWindowSize` — хук для отслеживания размера окна
- `shared/api/DebtorApi` — API для работы с должниками
