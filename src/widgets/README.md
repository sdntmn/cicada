# Слой `widgets`

## Назначение

Содержит виджеты — композитные блоки интерфейса, которые объединяют несколько фич и UI-компонентов для решения конкретной пользовательской задачи. Виджеты обычно используются на нескольких страницах и могут иметь собственное состояние.

## Структура

Каждый виджет имеет следующую структуру:

```
widgets/
  <WidgetName>/
    index.ts          # Публичный API (экспорт компонента виджета)
    ui/               # UI-компоненты виджета
      <ComponentName>/
        Component.tsx
        styles.scss
    model/            # (опционально) Логика состояния виджета (slice, thunk, types)
    lib/              # (опционально) Вспомогательная логика, специфичная для виджета
```

## Правила

- Виджеты могут зависеть от `features`, `entities`, `shared`.
- Виджеты не должны зависеть от `pages` (кроме случаев, когда виджет специфичен для одной страницы — тогда стоит рассмотреть, не является ли он частью страницы).
- Виджеты могут иметь собственное состояние, но если состояние является глобальным, его следует вынести в `entities` или `shared/store`.
- Избегайте создания виджетов, которые дублируют функциональность фич или сущностей.

## Примеры виджетов

- `BaseTable` — базовая таблица с настройками колонок, пагинацией, сортировкой
- `Notifications` — система уведомлений
- `SubNav` — вторичная навигация
- `TopNav` — верхняя навигационная панель
